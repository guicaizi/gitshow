# 2026-10-29

## 新增顶栏 ADB 框架替换模块（配对版）

- `server-adb.js`（新）：探测 adb、设备状态、本地目录/设备目录列举、同名自动配对、配对落盘
  （`.gdv/adb-pairs.json`）、按配对执行 root→remount→push→校验→sync→reboot，任务日志增量拉取。
  只在回环地址开放（复用 `isLoopbackRequest`）。
- `server.js`：`action.startsWith('adb-')` 的分支放在 `resolveRepo` 之前（接口与 git 无关）。
- `public/adb.js`（新）：顶栏绿点入口 + 两个视图——配对列表（勾选只执行选中项、刷新两端状态、
  展开详情）、双栏「添加配对」（左本地右设备，各带预览卡，可同名自动配对）。
- `public/app.js`：`openFinder(onPick)` 支持外部回调，ADB 选目录复用同一个选择器；
  `finderConfirm` 有回调时不打开仓库。
- 关键判断：目标路径不在 system/vendor 等分区时跳过 remount（避免无谓改动分区状态）。

## 坑

- Git Bash 会把 `D:\tmp\x` 参数转成 `D:/tmp/x`（传给 node/curl 时），测试要用文件或 `MSYS_NO_PATHCONV=1`，
  否则写进配对的路径会变成 `D://tmp//...`。已在 `writePairs` 里用 `path.resolve` 兜底归一化。
- 无头 Chrome 截图脚本：`Page.captureScreenshot` + `Emulation.setDeviceMetricsOverride`，
  面板类 UI 用它验证比人工点更快；用完记得关 chrome 并删 profile。
- 真机验证不能拿 /system/framework 试，改用 `/data/local/tmp/<dir>` 作为 remote，全链路可测且无风险。
