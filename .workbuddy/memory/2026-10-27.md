## 提交列表过滤（搜索框）失忆问题修复

- 现象：搜索框输入作者名后，点任意提交，列表又回到全部作者。
- 原因：过滤只对当前 DOM 的 `.commit-item` 改 `display:none`，而 `openCommit` / 勾选比对 / 滚动加载
  都会 `renderCommitList()` 重建 innerHTML，内联样式全丢。
- 改法：查询词进 `state.search`，新增 `applyCommitFilter()`（按 `state.commits[idx]` 的
  subject/author/email/short/hash/refs 匹配），`renderCommitList()` 重建后立刻重新筛一遍；
  `updateListFoot()` 统一算底部文案（过滤时显示「匹配 M / 已加载 N」，`can-more` 可点继续加载）。
- 附带：过滤时隐藏「工作区改动」条目（没有作者）；`q` 参数写进地址栏（`replaceState`），
  刷新/换分支后搜索框自动回填；底部提示行可点触发加载更多（过滤后可能一条都不剩、列表滚不动）。
- 涉及：`public/app.js`、`public/style.css`；已备份 `git-diff-viewer.bak-<时间>-public` 并上传服务器，
  纯静态改动，刷新即可，无需重启 node。

## 顶栏标题 / 标签页标题跟着项目名走

- 需求：多开几个标签页全是「Git 提交比对」，分不清是哪个仓库。
- 改法：`index.html` 的品牌 `span` 加 `id="brandName"`；`app.js` 新增 `syncTitle()`，
  取 `state.info.name`（服务端 `path.basename(repo)`）同时刷顶栏品牌与 `document.title`。
  打开仓库成功 / 失败回退 / `?mode=source` 初始化三处调用；无仓库时退回「Git 提交比对」。
- 标题格式：标签页 `仓库名 · Git 提交比对`，源码模式 `仓库名 · 源码浏览`。
- `style.css`：`#brandName` 限宽 240px + 省略号，完整名字与路径放 `title` 悬浮提示。
