# 项目约定

## 协作偏好（2026-10-24，用户反馈「流程太重」）

- **默认从简**：小改动（样式 / 文案 / 单个函数）只做 `node --check`、`node -c` 语法检查，
  不启动浏览器验证、不截图、不做多轮回归。
- 中大型改动（新接口、新视图、涉及异步竞态）才跑**一次**关键路径验证，不重复截图比对。
- 汇报控制在三句话内：改了什么、怎么用、已知风险。不写验证流水账、不堆表格。
- **只有 `server.js` 变了才重启服务**；`public/*` 静态文件改动刷新页面即可。
- 记忆只在有长期价值时写，不逐次追加。
- 用户说「直接改 / 不用测 / 别解释」时：改完 + 语法检查即结束，最多一句话结论。

## 项目边界

- 零依赖：只用 Node 内置模块 + 本机 git，不引入 npm 包、不加构建步骤。
- 默认监听 `127.0.0.1`，部署到服务器用 `HOST=0.0.0.0`，由 `start.sh` 管进程。
- 前端 `public/*` 为纯静态文件，改完刷新即生效。
- 代码注释沿用 prize 包裹规范（起止成对，日期 YYYYMMDD）。
