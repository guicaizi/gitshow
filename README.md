# Git 提交比对

一个跑在本地的网页版 git 历史查看器：左边看提交，右边看这次提交到底改了什么，也可以勾两个提交做跨版本比对。

历史部分只读；工作区支持暂存 / 取消暂存 / 忽略，以及带文件勾选与 amend 的提交。不对公网开放。

## 位置

```
D:\tools\git-diff-viewer\
```

整个目录可直接拷贝到别处使用，无依赖、无安装步骤。

## 启动

双击 `start.bat`，或在此目录执行：

```bash
node server.js
```

浏览器打开 <http://127.0.0.1:7391>，填入仓库路径（例如 `D:\code\my-project`）后点「打开」。

- 零依赖，只用 Node 内置模块 + 本机 git。
- 默认端口 7391，可用 `set PORT=8080 && node server.js` 修改。
- git 不在 PATH 时，会自动尝试常见安装位置，也可用环境变量 `GIT_BIN` 指定。

## 部署到 Linux 服务器（从 Windows 访问）

服务器上只要 Node（≥14）和 git，无需 `npm install`，整目录拷过去即可。

```bash
# 目录拷到服务器后
cd ~/tools/git-diff-viewer
HOST=0.0.0.0 ./start.sh start      # 后台启动，日志写 server.log
./start.sh status                  # 看是否在跑
./start.sh stop                    # 停止
HOST=0.0.0.0 ./start.sh            # 前台运行，Ctrl+C 停止
```

Windows 上直接浏览器打开：

```
http://192.168.1.202:7391/?repo=/home/yanliang/share/cursorProgect
```

- `HOST` 不设时仍只监听 `127.0.0.1`，只在服务器本机可用；`HOST=0.0.0.0` 才允许局域网访问。
- 页面里填的仓库路径是**服务器上的绝对路径**（Linux 用 `/`，例如 `/home/yanliang/share/N06`）。
- 开机自启（可选）：`crontab -e` 加一行 `@reboot cd $HOME/tools/git-diff-viewer && HOST=0.0.0.0 ./start.sh start`

**安全**：这是个无登录的服务，谁能访问这个端口，谁就能看到仓库内容、还能对仓库做暂存/提交。只在可信内网用；
不要映射到公网。服务器有防火墙时，只放行你自己的机器，例如
`firewall-cmd --add-rich-rule='rule family=ipv4 source address=192.168.1.50 port port=7391 protocol=tcp accept'`。

## 能做什么

**打开仓库**
- 路径框右侧的文件夹图标可以直接**浏览服务器磁盘**选仓库：单击目录只选中，双击进入，带 `git` 徽标的目录就是仓库
- 选中并打开后就记住了，下次刷新（或重开浏览器）自动打开这个仓库
- 换仓库时地址栏的 `?repo=` 会跟着更新，所以从带参数的链接进来再选别的目录，刷新也不会跳回上一个仓库；
  链接里找不到的仓库会自动回退到上次打开的那个
- 弹窗里的路径输入框可以直接粘完整路径回车跳转，「上一级」「主目录」用来快速移动

**看单个提交**
- 提交列表滚动加载，支持按提交信息 / 作者 / hash 搜索
- 分支、标签切换，从任意引用开始看历史
- 每个文件显示增删行数与状态（新增 / 修改 / 删除 / 重命名）
- 并排、内联两种 diff 视图，改动行做词级高亮
- 并排视图左右两栏之间的中线可以拖动，自由调整左右代码区的显示比例（双击复位，比例会记住）
- 文件筛选、单击文件头折叠、超长行自动换行、忽略空白变化

**跨版本比对**
- 勾选两个提交（列表右侧复选框），点「比对」查看两者之间的全部差异

**看未提交的改动**
- 仓库有未提交内容时，列表顶部会出现「工作区改动」，包含已暂存、未暂存和未跟踪文件
- 目录树上可按目录批量暂存、取消暂存、写入 `.git/info/exclude` 忽略；执行完原地刷新

**提交**
- 「提交…」按钮（仓库卡片上常驻，工作区视图工具条里也有）打开提交面板
- 面板列出暂存区的全部文件，可逐个勾选决定这次提交哪些（点整行即可勾选/取消）
- 下方是提交说明编辑框（第一行标题，空行后写详情），`Ctrl+Enter` 提交，`Esc` 关闭
- 勾选 `amend 上一次提交` 会自动带出上次提交说明，可只改说明、也可把新暂存的改动并进上次提交；若该提交已在远端分支，会提示需要强推
- 只提交选中的文件靠临时索引实现，未勾选的暂存内容会原样留在暂存区

**其他**
- 浅色 / 深色主题，记住上次打开的仓库
- 键盘 `j` / `k` 或上下方向键切换提交
- 点击短 hash 复制完整 hash
- 提交列表与文件树之间、文件树与 diff 之间的竖线都能拖动调宽（双击复位），宽度会记住
- 并排视图里 diff 中间那条竖线也能拖，左右两栏比例在 20%–80% 之间，双击回到 50/50

## 直接定位（可收藏）

```
http://127.0.0.1:7391/?repo=D:\code\my-project
http://127.0.0.1:7391/?repo=...&commit=abc1234
http://127.0.0.1:7391/?repo=...&cmp=abc123..def456
http://127.0.0.1:7391/?repo=...&working=1
```

可叠加 `&view=split|inline`、`&theme=light|dark`、`&wrap=1`。
